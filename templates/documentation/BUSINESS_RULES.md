# Plantilla: Reglas de operación

Propósito y ejemplo aplicado al kit: [documento de referencia](../../docs/business/BUSINESS_RULES.md).

Al adaptarlo: describir únicamente hechos confirmados de su proyecto, vincular requisitos y tareas, indicar responsable y fecha, y aportar evidencia reproducible. Si falta una decisión, declarar la pregunta y quién la resolverá. No copiar las capacidades de UASEK como si pertenecieran a su aplicación.

Guía de contenido para este documento: BR-01: no hay auditoría Git sin --authorize precedido de consentimiento humano. BR-02: dependencia incompleta bloquea inicio y cierre. BR-03: evidencia debe existir en root y no ser archivo sensible. BR-04: init y backup no reemplazan destinos. BR-05: ningún proveedor manual puede usarse como API nativa. BR-06: scripts de terceros no se ejecutan durante análisis o auditoría.
