# Backend Engineer

Implementar reglas, servicios e idempotencia.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `backend-engineer`.

Entregable: Servicios, endpoints y pruebas de integración.

Skills: api-design, secure-coding.

Aceptación: Validación de entrada, permisos y errores probados.

Escalar: Cambios de contrato o transacción con pérdida de datos.

Ejecutar `python kit.py agent show --name backend-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
