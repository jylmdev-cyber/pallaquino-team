# Un equipo con memoria compartida

PALLAQUINO TEAM organiza el trabajo de ingeniería asistido por IA en tareas verificables, contratos de roles, memoria durable y automatizaciones locales. La plataforma conserva los identificadores técnicos UASEK para mantener la compatibilidad de su CLI, instalación y formatos.

## Qué problema resuelve

Los cambios de asistente, las sesiones interrumpidas y las tareas paralelas pueden perder decisiones o duplicar trabajo. La memoria versionada conserva requisitos, contexto y evidencia. La coordinación usa dependencias y reservas de archivos; los checkpoints permiten preparar una recuperación sin sobrescribir el árbol actual.

## Capas existentes

1. **Kit universal UASEK:** CLI Python, PROJECT MEMORY, perfiles, skills, plantillas, auditoría autorizada, pruebas y continuidad.
2. **Engineering Intelligence Platform:** PROJECT BRAIN, permisos, trabajos paralelos, gates, revisión, extensiones y operaciones multiproyecto.
3. **Universal Documentation Portal:** estas guías, fichas derivadas, búsqueda local y publicación estática preparada para GitHub Pages.

## Alcance y público

Para desarrolladores, responsables técnicos, QA, seguridad y operadores que trabajan con asistentes de IA. Los agentes son contratos de roles; no se ejecutan veintiún modelos por abrir el kit. Las referencias sectoriales son especificaciones adaptables. No hay un servidor REST de producción ni un despliegue cloud preconfigurado.
