# Observabilidad

Mutaciones registran at, command y outcome en .uasek/events.jsonl. El contenido de prompts no se registra. stdout entrega JSON redactado y códigos de salida para integración. test conserva last-test.json con comando, salida acotada, resultado y huella. No hay servicio daemon, métricas en red ni alertas automáticas.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
