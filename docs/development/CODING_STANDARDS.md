# Convenciones

Python 3.11+, biblioteca estándar, procesos con argv y shell=False, errores esperados KitError y códigos no cero. Rutas mutables se resuelven con safe_path. Escribir archivos individuales atómicamente cuando corresponda y respetar locks de memoria. No imprimir secretos ni incorporar dependencias para una operación ya cubierta por stdlib. IDs de skills en minúsculas con guiones.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
