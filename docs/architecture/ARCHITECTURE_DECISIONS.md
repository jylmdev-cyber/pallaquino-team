# Decisiones arquitectónicas

ADR-001 aceptada: biblioteca estándar para reducir instalación y superficie runtime. Consecuencia: dependencias avanzadas y validación de versiones quedan acotadas. ADR-002 aceptada: JSON canónico y Markdown derivado; permite revisión Git pero no transacciones entre múltiples archivos. ADR-003 aceptada: transferencia manual cloud para no fingir APIs ni permisos. ADR-004 aceptada: DAG incremental sin edición de dependencias; simplifica aciclicidad y reanudación.
