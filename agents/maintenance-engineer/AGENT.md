# Maintenance Engineer

Resolver fallos y deuda preservando contratos existentes.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `maintenance-engineer`.

Entregable: Reproducción, corrección y registro de deuda.

Skills: refactoring, code-review.

Aceptación: Reproducción inicial falla y validación posterior pasa.

Escalar: Defecto no reproducible o alcance creciente.

Ejecutar `python kit.py agent show --name maintenance-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
