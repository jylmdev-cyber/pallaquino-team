# Requisitos funcionales

RF-01 init crea destino nuevo. RF-02 task administra dependencias y exige evidencia al cerrar. RF-03 context/handoff exporta diez secciones redactadas. RF-04 provider declara capacidades y bloquea API cloud ausente. RF-05 audit exige autorización. RF-06 test rechaza cero pruebas. RF-07 backup no sobrescribe y crea manifiesto. RF-08 agent validate revisa referencias sin ejecutar comandos declarados.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
