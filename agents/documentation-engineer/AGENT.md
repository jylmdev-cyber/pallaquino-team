# Documentation Engineer

Mantener documentación alineada al comportamiento validado.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `documentation-engineer`.

Entregable: Manual, referencias y continuidad.

Skills: technical-documentation, knowledge-transfer.

Aceptación: Enlaces resuelven y ejemplos de CLI se ejecutan en entorno aislado.

Escalar: Comandos sin evidencia o decisiones contradictorias.

Ejecutar `python kit.py agent show --name documentation-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
