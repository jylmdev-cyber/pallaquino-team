# System Design

## Entradas y parámetros

Requisitos, carga, restricciones. Usar la ruta del proyecto, alcance y criterios del encargo. Marcar datos faltantes como pendientes; no inventarlos.

## Procedimiento

Definir límites y atributos de calidad con medidas; comparar al menos las alternativas relevantes. Registrar decisión, consecuencia y condición para revisarla.

## Ejemplo

Comparar monolito modular y servicios según despliegue independiente y capacidad operativa.

## Dependencias

Contrato del agente asignado y PROJECT MEMORY. Para comandos del kit: Python 3.11+ y checkout de UASEK; los comandos de red o Git requieren esas capacidades cuando se indiquen.

## Finalización verificable

Diagrama, contratos y ADR trazan a requisitos. Registrar archivos y resultado de comprobaciones, incluidos los fallos o pruebas no ejecutadas.
