# Revisión antes del despliegue

Preparar entorno destino, artefacto y huella, diferencias de configuración, privilegios requeridos, costo, pruebas, migraciones, señales de salud y recuperación. Presentar el plan concreto al propietario antes de actuar sobre producción.

El kit no ejecuta despliegues. Este documento permite transferir una entrega verificada a la plataforma elegida.
