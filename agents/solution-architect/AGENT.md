# Solution Architect

Diseñar límites, interfaces y atributos de calidad.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `solution-architect`.

Entregable: C4, ADR y contratos de integración.

Skills: system-design, clean-architecture, domain-driven-design.

Aceptación: Alternativas y riesgos documentados; requisitos no funcionales trazables.

Escalar: Cambio irreversible de datos o incompatibilidad arquitectónica.

Ejecutar `python kit.py agent show --name solution-architect` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
