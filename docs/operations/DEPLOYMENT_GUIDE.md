# Distribución y despliegue

Este producto se distribuye como ZIP/paquete Python; no despliega aplicaciones de negocio. Para usar: extraer, ejecutar doctor y tests. Para preparar una versión de un proyecto: completar tareas, ejecutar test y security y luego release --version X.Y.Z. Revisar artefacto, entorno, migraciones y recuperación antes de autorizar despliegue externo.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
