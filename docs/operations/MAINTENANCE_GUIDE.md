# Mantenimiento

Revisar fuentes oficiales del stack y dependencias periódicamente mediante tarea explícita. Mantener schema compatible o implementar migrador versionado antes de cambiarlo. Actualizar manuales, pruebas y contratos junto con cambios. Exportar handoff al concluir un incremento y conservar estado validado. La herramienta no instala actualizaciones ni borra deuda automáticamente.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
