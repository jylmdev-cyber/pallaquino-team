# Historial de versiones

Sin nueva versión — nombre del proyecto actualizado a PALLAQUINO TEAM en la presentación, ayuda CLI y memoria portable. Se conservan los identificadores técnicos del núcleo y los registros históricos de entregas anteriores.

UDP edición 1 — portal VitePress para el software 2.0.0: guías en español, catálogos derivados, referencia CLI/AST, búsqueda local, Mermaid, temas y scripts de sincronización. Workflows separados de validación/publicación; Pages deshabilitado hasta habilitación y autorización. Sin cambios de versiones de memoria ni de la API EIP.

2.0.0 — 2026-10-21: segunda capa Engineering Intelligence Platform: PROJECT BRAIN y transferencia neutral, trabajos paralelos aislados con leases y reservas, permisos/autonomía, quality gates de cierre, regresión y recuperación, mapa Python AST, routing por metadatos, extensiones versionadas y adaptadores de proceso revisados, registro multiproyecto, trazabilidad documental y centro de operaciones HTML local. Se conservan memoria y CLI anteriores; activar EIP añade enforcement de política.

1.1.0 — 2026-10-21: contexto universal JSON v1 con importación y checksum; instrucciones de proveedor separadas; checkpoints con código, memoria, pruebas y recuperación en carpeta nueva; selección de roles por reglas con presupuesto y planes idempotentes. Memoria local conserva schema 1 y los comandos anteriores.

1.0.0 — 2026-10-21: primera entrega del CLI, memoria schema 1, tareas dependientes, contratos/skills, transferencias manuales, adaptador Ollama local, inventario y seguridad parcial, pruebas y empaquetado. No hay versiones anteriores migradas.
