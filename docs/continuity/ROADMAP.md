# Evolución propuesta

Implementado en 1.1: contexto universal JSON v1 e importación, checkpoints de fuentes con recuperación aislada y selección de roles por reglas con presupuesto. Mantener como posibles extensiones: nuevos formatos con migración explícita, firma criptográfica de paquetes, respaldos cifrados de producción, coordinación distribuida y evaluación semántica de criterios. La selección actual es determinista y explicable; no se afirma comprensión semántica completa.

Priorizar según necesidad real: runners adicionales con contratos explícitos; validadores semánticos por tipo de entregable; adaptadores cloud autenticados; parsers de locks adicionales; sincronización de memoria; firma y restauración segura de respaldos. Cada extensión requiere criterios, pruebas y autorización para efectos externos. No son funcionalidades actuales.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
