# Reglas de operación

BR-01: no hay auditoría Git sin --authorize precedido de consentimiento humano. BR-02: dependencia incompleta bloquea inicio y cierre. BR-03: evidencia debe existir en root y no ser archivo sensible. BR-04: init y backup no reemplazan destinos. BR-05: ningún proveedor manual puede usarse como API nativa. BR-06: scripts de terceros no se ejecutan durante análisis o auditoría.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
