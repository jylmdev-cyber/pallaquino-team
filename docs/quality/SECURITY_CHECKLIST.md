# Controles de seguridad

Revisar rutas, datos no confiables, privilegios y secretos. scan es heurístico y no cubre binarios o archivos >1 MB. Backups de fuentes omiten archivos sensibles, pero no sustituyen almacenamiento cifrado. Auditar dependencias requiere versión exacta y consulta explícita; formatos desconocidos no son seguros por defecto. No se incluyen operaciones de borrado, reset, push, despliegue o restauración destructiva. Referencia: docs/standards/REFERENCES.md.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
