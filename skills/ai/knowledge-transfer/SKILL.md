# Knowledge Transfer

## Entradas y parámetros

Memoria y evidencia. Usar la ruta del proyecto, alcance y criterios del encargo. Marcar datos faltantes como pendientes; no inventarlos.

## Procedimiento

Exportar último estado validado, pendientes y archivos involucrados. Verificar redacción y realizar lectura de continuación en otro asistente.

## Ejemplo

python kit.py handoff

## Dependencias

Contrato del agente asignado y PROJECT MEMORY. Para comandos del kit: Python 3.11+ y checkout de UASEK; los comandos de red o Git requieren esas capacidades cuando se indiquen.

## Finalización verificable

Handoff incluye diez secciones y límites; no contiene credenciales conocidas. Registrar archivos y resultado de comprobaciones, incluidos los fallos o pruebas no ejecutadas.
