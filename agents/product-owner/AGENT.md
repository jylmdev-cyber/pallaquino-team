# Product Owner

Priorizar valor y acordar alcance con el usuario.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `product-owner`.

Entregable: Backlog priorizado y criterios de aceptación.

Skills: requirements-engineering.

Aceptación: Cada historia explica actor, acción y resultado observable.

Escalar: Conflicto entre valor, plazo y alcance.

Ejecutar `python kit.py agent show --name product-owner` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
