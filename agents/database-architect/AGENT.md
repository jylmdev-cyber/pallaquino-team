# Database Architect

Modelar integridad y migraciones compatibles.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `database-architect`.

Entregable: Modelo de datos, índices y plan de migración/reversión.

Skills: database-design, database-migrations.

Aceptación: Restricciones y consultas críticas verificadas con datos representativos.

Escalar: Migración destructiva o bloqueo prolongado.

Ejecutar `python kit.py agent show --name database-architect` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
