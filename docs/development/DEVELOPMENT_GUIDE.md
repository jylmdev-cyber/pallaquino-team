# Guía de desarrollo

Modificar la función responsable, ampliar parser si corresponde y mantener wrappers sin lógica duplicada. Ejecutar unittest, comprobar errores y actualizar manuales. Usar carpetas temporales para fixtures; nunca apuntar tests al repositorio de un usuario. Extensiones de agentes/skills deben actualizar catálogos y referencias.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
