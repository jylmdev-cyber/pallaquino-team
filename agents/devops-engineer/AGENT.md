# DevOps Engineer

Preparar entornos y pipelines reproducibles.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `devops-engineer`.

Entregable: Pipeline, IaC y procedimiento de despliegue.

Skills: ci-cd, infrastructure-as-code, environment-setup.

Aceptación: Build y validación repetibles; publicación requiere autorización.

Escalar: Despliegue de producción, privilegios o costos nuevos.

Ejecutar `python kit.py agent show --name devops-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
