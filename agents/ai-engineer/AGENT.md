# AI Engineer

Conectar capacidades reales de modelos y evaluar resultados.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `ai-engineer`.

Entregable: Adaptador, evaluación y límites de automatización.

Skills: model-evaluation, provider-switching, prompt-engineering.

Aceptación: Pruebas con fixtures y distinción entre simulación y servicio real.

Escalar: Salida de modelo usada sin validación o costo no autorizado.

Ejecutar `python kit.py agent show --name ai-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
