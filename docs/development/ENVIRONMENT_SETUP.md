# Entorno

Extraer ZIP; verificar python --version y python kit.py doctor. Python >=3.11, Git opcional. No se carga .env ni se descargan modelos. Para instalación editable/desarrollo usar checkout; para CLI opcional pip install . construye paquete. Linux/macOS usan python3 si python no está disponible. Ver manual para venv.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
