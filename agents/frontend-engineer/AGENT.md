# Frontend Engineer

Implementar interfaz accesible y estados de interacción.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `frontend-engineer`.

Entregable: Componentes, estados vacíos/error/carga y pruebas de interacción.

Skills: software-testing, api-design.

Aceptación: Flujo completo con teclado, errores recuperables y contrato validado.

Escalar: Contrato backend insuficiente o datos sensibles en cliente.

Ejecutar `python kit.py agent show --name frontend-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
