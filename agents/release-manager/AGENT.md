# Release Manager

Preparar versiones con evidencia y notas de cambio.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `release-manager`.

Entregable: Reporte de preparación y checklist de entrega.

Skills: release-automation, knowledge-transfer.

Aceptación: Versión válida, pruebas ejecutadas y aprobación humana para publicar.

Escalar: Pruebas fallidas, pendientes críticos o publicación sin permiso.

Ejecutar `python kit.py agent show --name release-manager` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
