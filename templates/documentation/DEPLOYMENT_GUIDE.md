# Plantilla: Distribución y despliegue

Propósito y ejemplo aplicado al kit: [documento de referencia](../../docs/operations/DEPLOYMENT_GUIDE.md).

Al adaptarlo: describir únicamente hechos confirmados de su proyecto, vincular requisitos y tareas, indicar responsable y fecha, y aportar evidencia reproducible. Si falta una decisión, declarar la pregunta y quién la resolverá. No copiar las capacidades de UASEK como si pertenecieran a su aplicación.

Guía de contenido para este documento: Este producto se distribuye como ZIP/paquete Python; no despliega aplicaciones de negocio. Para usar: extraer, ejecutar doctor y tests. Para preparar una versión de un proyecto: completar tareas, ejecutar test y security y luego release --version X.Y.Z. Revisar artefacto, entorno, migraciones y recuperación antes de autorizar despliegue externo.
