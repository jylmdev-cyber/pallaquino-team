# Referencias documentales

Usar prácticas pertinentes, sin declarar certificación o cumplimiento formal por emplearlas. El kit no reproduce textos normativos ni certifica aplicaciones.

| Referencia | Aplicación en el kit |
|---|---|
| ISO/IEC/IEEE 29148 | Trazabilidad entre requisitos, historias y aceptación |
| ISO/IEC/IEEE 42010 | Decisiones, restricciones y vistas arquitectónicas |
| ISO/IEC 25010 | Atributos de calidad con medidas acordadas |
| [OWASP](https://owasp.org/) | Amenazas, acceso y pruebas según superficie |
| [OpenAPI](https://spec.openapis.org/oas/latest.html) | Plantilla de contrato para proyectos futuros |
| [C4](https://c4model.com/) | Vistas de contexto/componentes adecuadas a la escala |
| [ADR](https://adr.github.io/) | Decisión, contexto y consecuencias |
| [SemVer](https://semver.org/) | Versiones de entrega |
| [Conventional Commits](https://www.conventionalcommits.org/) | Convención opcional de mensajes; auditoría solo muestra muestra |

Los requisitos legales dependen de jurisdicción, sector y datos. Las referencias por rubro piden verificar ese contexto; no inventan obligaciones ni sustituyen revisión competente.
