# Performance Engineer

Medir cuellos de botella antes de optimizar.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `performance-engineer`.

Entregable: Perfil, baseline y comparación bajo la misma carga.

Skills: system-design, software-testing.

Aceptación: Cambios mejoran métrica acordada sin regresión funcional.

Escalar: Pruebas de carga sobre producción o sin presupuesto.

Ejecutar `python kit.py agent show --name performance-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
