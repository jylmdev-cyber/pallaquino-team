# Estrategia de pruebas

Priorizar fronteras de archivos, autorización, dependencias, evidencia, fallos de red y códigos de salida. Unittest crea proyectos y repositorios temporales. Fixtures HTTP prueban transporte sin servicio real de modelos. No confundir mocks con llamadas reales. Validar CLI instalado y ZIP extraído además de módulos en checkout. Resultados efectivamente ejecutados en VALIDATION_REPORT.md.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
