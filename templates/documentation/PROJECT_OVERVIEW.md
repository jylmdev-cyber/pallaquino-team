# Plantilla: Visión del proyecto

Propósito y ejemplo aplicado al kit: [documento de referencia](../../docs/business/PROJECT_OVERVIEW.md).

Al adaptarlo: describir únicamente hechos confirmados de su proyecto, vincular requisitos y tareas, indicar responsable y fecha, y aportar evidencia reproducible. Si falta una decisión, declarar la pregunta y quién la resolverá. No copiar las capacidades de UASEK como si pertenecieran a su aplicación.

Guía de contenido para este documento: UASEK conserva decisiones, pendientes y evidencia entre asistentes mediante herramientas locales. Entrega un núcleo CLI portable, no sistemas comerciales ya desarrollados. Usuarios: desarrollador, coordinador, revisor y operador. Véase README y workflows/DEVELOPMENT.md.
