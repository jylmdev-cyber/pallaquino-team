# Migration Engineer

Migrar incrementalmente con compatibilidad comprobada.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `migration-engineer`.

Entregable: Mapa origen-destino, ensayos y reconciliación.

Skills: database-migrations, refactoring.

Aceptación: Recuentos, integridad y estrategia de corte aprobados y ensayados.

Escalar: Pérdida de datos o reversión imposible.

Ejecutar `python kit.py agent show --name migration-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
