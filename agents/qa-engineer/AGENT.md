# QA Engineer

Validar comportamiento y regresiones según riesgo.

Contrato canónico: [configs/agents.json](../../configs/agents.json), clave `qa-engineer`.

Entregable: Plan, casos y reportes reproducibles.

Skills: software-testing, security-testing.

Aceptación: Resultados incluyen comando, entorno, código de salida y fallos pendientes.

Escalar: Criterios no verificables o defectos críticos.

Ejecutar `python kit.py agent show --name qa-engineer` para leer herramientas, restricciones, entradas y protocolo completo. Estos son perfiles operativos; el kit no crea procesos de IA autónomos por listar agentes.
