# Calidad y cobertura

La evidencia ejecutada se centraliza en VALIDATION_REPORT.md y validation/ de la distribución para evitar cifras duplicadas. Las pruebas locales verifican el núcleo CLI. No prueban que un asistente cumpla por sí solo contratos, que un modelo real produzca código correcto ni que las plantillas satisfagan requisitos legales de un país. El pipeline propuesto amplía plataformas cuando se ejecute.
