# Criterios de aceptación

AC-01: init en carpeta existente devuelve 2 y conserva contenido. AC-02: task done sin evidencia falla. AC-03: audit sin autorización no invoca Git. AC-04: handoff omite .env y redacta patrones conocidos. AC-05: fallos de OSV no producen estado limpio. AC-06: docs conserva archivos humanos. AC-07: tests vacíos no habilitan release. AC-08: cambio de código invalida el reporte de test para release. Evidencia ejecutable en tests/test_core.py.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
