# Visión del proyecto

UASEK conserva decisiones, pendientes y evidencia entre asistentes mediante herramientas locales. Entrega un núcleo CLI portable, no sistemas comerciales ya desarrollados. Usuarios: desarrollador, coordinador, revisor y operador. Véase README y workflows/DEVELOPMENT.md.

Ver [manual de usuario](../user-manual/MANUAL.md) y [manual técnico](../technical-manual/MANUAL.md).
